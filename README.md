# CODEBRIDGE — オンラインITスクール LP / ポートフォリオ作品

架空のオンラインITキャリアスクール「CODEBRIDGE（コードブリッジ）」の集客用ランディングページです。
未経験からのキャリアチェンジという、意思決定に時間がかかるジャンルを想定し、
**不安の解消**と**自分ごと化**を軸にしたLPとして制作しています。

## デモの見方

`index.html` をブラウザで開くだけで動作します（ビルド不要）。
画像はダウンロード済みでローカル参照のため、CDN（Bootstrap等）以外はオフラインでも表示されます。

## この作品で見せたいこと

1本目のLP（FORMA・パーソナルジム）は「明るい配色・即断即決・BtoC店舗」でした。
本作は意図的に**濃紺×バイオレット×アンバーのテック系トーン**、**検討期間が長いオンライン商材**という
異なる文脈を選び、同じLPというフォーマットの中でも表現の引き出しがあることを示しています。

- **多段階クイズ（ウィザードUI）**：FORMAの「入力すると即座に数値が変わる」シミュレーターとは異なり、
  1問ずつ進める・戻れる・診断結果に応じて表示を出し分けるステート管理を実装（`main.js` の適性診断部分）
- **給付金シミュレーター**：日本の実在制度（教育訓練給付金）を題材にした試算ツール。
  コースによって給付金対象の可否が異なるという実務的な制約をUIに反映し、
  対象外コースを選ぶとチェックボックスが自動的に無効化される仕組みにしています
- **転職の前後比較**：FORMAの体重Before/Afterと構造は近いですが、「職種」「年収」という
  ジャンル特有の指標に置き換えることで、テンプレートの使い回しではなく設計し直していることを示しています

## 使用技術

- HTML5 / CSS3 / JavaScript（バニラJS、フレームワークなし）
- [Bootstrap 5.3](https://getbootstrap.com/)（CDN）— グリッド、アコーディオン、フォームバリデーション表示
- [Bootstrap Icons 1.11](https://icons.getbootstrap.com/)（CDN）
- [Swiper 11](https://swiperjs.com/)（CDN）— 受講生の声カルーセル
- [AOS 2.3](https://michalsnik.github.io/aos/)（CDN）— スクロール連動アニメーション
- Google Fonts（Sora / Noto Sans JP）
- 画像は [Unsplash](https://unsplash.com/) と [Pexels](https://www.pexels.com/) からダウンロードし、`assets/img/` に同梱（オフラインでも表示可能）

## 実装のポイント

- **BEM 記法**：`block__element--modifier` で設計。レイアウトは `l-`、JS参照は `js-` プレフィックスで責務を分離
- **CSS 設計**：配色・角丸・影・フォントを `:root` のカスタムプロパティに集約
- **クイズのステート管理**：質問ごとのスコアをオブジェクトで集計し、最多得点のコースを結果として表示。
  「戻る」ボタンでも回答済みのスコアは保持したまま、進捗バーとステップ表示のみを戻す設計
- **シミュレーターの整合性**：料金カードの「給付金対象外」表示とシミュレーターの計算結果が矛盾しないよう、
  コースごとの対象可否をJS側で一元管理
- **アクセシビリティ**：`aria-expanded` / `aria-live` の付与、`prefers-reduced-motion` でのアニメーション無効化
- **フォールバック**：JavaScript が読み込めない環境でも、`no-js` クラスの除去処理と AOS 属性の除去によりコンテンツが表示されます

## 動作確認済みの項目

- 適性診断クイズ：Web/データ/デザインそれぞれが最多になる回答パターンで正しいコースを表示、戻る・やり直しの動作
- 給付金シミュレーター：コース別の受講料・給付金額（70%・上限56万円）・実質負担額の計算、
  UI/UXデザインコース選択時にチェックボックスが無効化され給付金が¥0になること
- 申し込みフォーム（未入力ブロック・正常送信でリセット＋完了表示）
- スマホ幅（390px）でのナビ開閉、横スクロールが発生しないこと
- 全10点の画像読み込み、コンソールエラーなし

## 注意事項

- スクール名・所在地・メンター名・卒業生の実績・数値はすべて架空の設定です。
- 掲載写真はイメージであり、記載の実績とは関係ありません。
- 「給付金シミュレーター」は一般的な制度を参考にした試算表示で、給付を保証するものではありません。
  実際の対象可否・給付額は個人の雇用保険加入状況によって異なり、最終的にはハローワークの審査で確定します。
- フォームは送信処理を持たないデモです（送信ボタンで完了メッセージのみ表示）。
